# Mohammed Farag Abdel Aziz — Portfolio

Professional portfolio for Mohammed Farag Abdel Aziz, a third-year Railway Technology student at October Technological University. The page presents his education, railway and industrial training, technical and soft skills, and two engineering projects.

The site is built with static HTML, CSS and JavaScript. Profile photographs and the railway background are stored in `assets/`; the two project images are stored in `assets/projects/`.

## Deploy to GitHub Pages

This site has no build step. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish `index.html` and the referenced assets.

## Deploy to Vercel

Import the repository into Vercel using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` contains these settings; no build step or dependencies are required.
